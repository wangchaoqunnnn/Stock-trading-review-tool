# Stock-trading-review-tool

AI生成的炒股复盘工具：本地运行的 A 股每日复盘网页，数据来自东方财富公开行情接口，盘中每 30 秒自动刷新。

## 功能

- 指数快照：上证指数、深证成指、创业板指、科创50、沪深300、北证50
- 市场温度：两市成交额、上涨/下跌/平盘、涨停/炸板/跌停、最高连板、竞价涨停、炸板率
- 策略信号检查表：按短线框架逐项显示“满足/未满足”
- 板块强弱：行业涨幅榜、行业主力净流入榜、概念主力净流入榜
- 主力资金：净流入 TOP10、净流出 TOP10
- 涨停复盘：涨停行业分布、连板梯队、09:25 竞价封板、观察池
- 当日快讯：按市场关键词过滤的财经快讯
- 实时盘口页（Tab 切换）：大盘情绪、板块过滤器、盘中确认观察池、盘中节奏
  - 自动轮询板块涨停数、主力净流入、量比、首封时间、炸板数
  - 个股分时均价线、突破前高/竞价高点、回踩、直线拉升、炸板回封等买点信号
  - 昨日涨停今日溢价、炸板率、上涨/下跌家数等情绪指标
- 量价异动页（Tab 切换）：全A扫描，按“放量上攻、放量滞涨、冲高回落、缩量上涨、放量下跌、缩量回踩”分类
  - 自动轮询量比、换手、成交额、5日均量、MA20、20日新高、板块资金净流入
- 涨停回踩页（Tab 切换）：筛选20日内涨停过、上升趋势、缩量回踩不破涨停、且属于市场热点的股票
  - 输出距涨停天数、涨停日期、5日量比、MA20、板块资金、热点标签与评分

## 短线策略文字版

### 总原则

短线没有“出现信号就能买”这回事。信号只负责提高胜率，买入还需要确认、市场环境、仓位、止损四件事同时成立。

### 1. 竞价阶段（9:15-9:25）

- 看高开幅度：0%~3% 的健康高开最常见；高开 7% 以上要防冲高兑现；一字板或竞价涨停看封单是否够大。
- 看竞价量能：量比明显放大代表资金抢筹；缩量高开多半是虚的。
- 看竞价结构：价格在竞价中被一路买上去，比反复砸下来再拉回更可靠。
- 看板块联动：龙头竞价强势，同时同板块多只高开，才是板块启动；只有一只票高开不算强。

### 2. 盘中资金与分时

- 量比：早盘和全天量比在 1.5~2 以上，放量才有持续性；缩量上涨尽量不追。
- 换手：主板活跃区约 5%~15%，小市值可更高；换手太低没博弈，太高要防出货。
- 分时：股价站上分时均价线、回踩不破、放量突破平台，比单纯看涨幅更有效。
- 大单/主力净流入：最好持续为正，而不是开盘冲一下随后一路流出。
- 涨停质量：首板越早越强（10 点前最佳）；封单金额相对流通市值越大越稳；炸板后快速回封比一直不炸更强。

### 3. 板块与题材

- 看板块涨幅、板块内涨停家数、板块主力净流入。
- 看有没有完整梯队：龙头打高度、卡位股跟风、低位股补涨；只有龙头孤军奋战，持续性差。
- 看有没有新催化：政策、订单、业绩、海外映射都算。
- 板块处在启动初期比高潮期安全，追连续大涨几天的主线容易接最后一棒。

### 4. 市场情绪周期

- 盯连板高度、涨停家数、炸板率、昨日涨停股今日溢价。
- 冰点后的修复期短线胜率相对高；高潮后的退潮期追高胜率明显下降。
- 大盘上涨家数大于下跌家数、有明确主流板块时，短线环境才好做。

### 5. 个股筹码与纪律

- 龙头优先，跟风次之；不碰已经连续加速、高位放巨量滞涨的票。
- 注意解禁、减持、业绩雷、ST 和立案风险。
- 买入要有确认理由：竞价抢筹确认、分时放量突破、回踩不破低吸，三选一。
- 仓位分成试探仓和确认仓；止损提前定，比如跌破当日分时均价、跌破 5 日线、涨停打开不回封。

### 什么时候才算“勉强可以小仓试探”

题材有新催化 + 板块涨停至少 3 家 + 龙头竞价高开放量 + 量比大于 2 + 指数环境不差 + 个股在板块里有地位。即便都满足，也只是提高胜率，不是保证盈利。

### 需要警惕的假信号

- 高开冲高回落
- 量比放大但主力净流出
- 板块涨停家数少
- 龙头炸板
- 指数下跌家数持续扩大
- 高位股集体跌停

## 实时盘口策略文字版

复盘负责选票，盘中只负责确认和上车。盘中盯的不是新逻辑，而是资金有没有按复盘时的预期走。

### 买之前先看大盘情绪

- 指数是否站在分时均价线上方，有没有单边跳水；
- 上涨家数和下跌家数；
- 昨日涨停股今天开盘溢价如何，炸板率高不高；
- 环境差的时候，再强的个股也要打折，宁可空仓。

### 板块是最关键的过滤器

- 板块涨幅和板块主力净流入是否为正、是否在扩大；
- 板块内涨停家数、龙头是否封住；
- 只买板块里的龙头或卡位股，不买最后排跟风；
- 个股强、板块弱，是最常见的陷阱。

### 个股分时买点

- 股价站上分时均价线，回踩不破；
- 放量突破前高、平台或竞价高点；
- 不追已经垂直拉升的直线票，等第一次回踩确认；
- 涨停票重点看封单大小、炸板次数、回封速度。

### 资金和盘口

- 主力净流入盘中实时为正，且不是开盘冲一下就开始流出；
- 量比明显放大，换手处于健康区间；
- 大单主动买，而不是对倒拉抬；
- 特别警惕“量比很大但主力净流出”的诱多盘。

### 买之前先定位置和止损

- 确认买点是“刚突破”或“回踩不破”，而不是高位放量滞涨；
- 止损位提前定好：跌破分时均价线、竞价低点、平台支撑，任何一个触发就走；
- 仓位分试探仓和确认仓，不满仓、不补高位套牢仓。

### 盘中时间节奏

- 9:25-9:30：看竞价高开、量比、板块联动；
- 9:30-10:00：看资金是否持续流入，板块涨停是否扩散，等第一次回踩不破；
- 10:00-11:30：看板块有没有形成合力，早盘冲高回落、运行在均价线下方就放弃；
- 13:00-14:30：看午后有没有分歧转一致、炸板后回封；
- 14:30 后：看尾盘封单稳不稳，强势票尾盘跳水要警惕次日低开。

### 盘中最容易犯的错

- 只看个股不看板块；
- 追直线拉升；
- 高开低走还一路补仓；
- 没有止损位就买；
- 盘中临时起意，而不是从复盘池里挑票。

### 页面自动轮询

盘中有自动轮询板块涨停数、主力净流入、量比、首封时间和炸板数，盘中只需要盯筛选结果和确认条件。

## 量价异动策略文字版

量价异动，简单说就是“成交量和价格，出现了和它自己历史常态明显不同的变化”。它不是单一指标，而是一组“量能 + 价格行为”的组合判断。

### 常见量价异动类型

| 类型 | 特征 | 含义 |
| --- | --- | --- |
| 放量突破 | 量比≥2，价格放量突破平台/均线 | 资金进场，相对健康 |
| 放量滞涨 | 量能大幅放大，但涨幅很小或冲高回落 | 分歧加大，可能是出货 |
| 缩量上涨 | 涨幅不错，但量能反而萎缩 | 高度控盘，或买盘不足 |
| 放量下跌 | 下跌时量能显著放大 | 恐慌抛售或主力出货 |
| 缩量回踩 | 回调时量能明显萎缩 | 抛压衰竭，可观察 |

真正值得找的是“量价配合”的异动，比如：低位/平台整理后放量突破、缩量回踩不破再放量启动。而“高位放量滞涨”“放量下跌”属于要回避的异动。

### 如何实时找出量价异动股

- 盘口指标：量比 ≥ 2；量比 ≥ 3 属于强异动；成交额 ≥ 5 亿；换手率 5%-20%；涨速 > 2% 且量能同步放大。
- 相对自身历史：当日成交量 / 过去5日均量 ≥ 1.5-2 倍；前期连续缩量整理，今日首次放量；价格突破近10日或20日平台高点；成交额创近20日新高但股价还没大涨，属于“量先行”。
- 板块和大盘配合：板块整体放量、板块内多只个股同时异动更可靠；大盘弱势时，个股逆势放量上涨是更强的独立信号；板块资金净流入为正更稳。
- 分时确认：股价站在分时均价线上方，回踩不破；大单/主力净流入持续为正；早盘放量突破前高，而不是高开低走。

### 实战筛选条件示例

量比 ≥ 2、成交额 ≥ 5 亿、涨幅 1%~7%（不追已涨停）、换手率 5%~20%、现价 > MA20、5日量能先缩后放、板块资金净流入 > 0。

量价异动只是“信号”，不是“买点”。找出来后还要结合板块强度、分时均价线和止损位一起判断。

页面自动扫全A，按“放量上攻、放量滞涨、冲高回落、缩量上涨、放量下跌、缩量回踩”六类列出。


## 涨停回踩策略文字版

过滤20日内有涨停过、处于上升趋势、缩量回踩不破涨停，并且有市场热点的股票。

### 筛选条件

- 20日内有涨停：最近20个交易日内出现过涨停，按 10%/20%/30% 板块阈值区分。
- 上升趋势：现价站上 MA20，MA20 向上，近5日低点相对前10日低点抬高。
- 缩量回踩不破：当日量比≤1.2，当日成交量低于5日均量0.85倍，今日最低价不低于涨停日低点/收盘价的98%。
- 市场热点：所属行业板块涨幅为正且主力净流入为正，或板块当日有涨停。
- 流动性过滤：成交额≥5亿，涨幅-5%~3%，量比≤1.2。

### 页面输出

输出代码、名称、现价、涨跌幅、量比、5日量比、换手、成交额、主力净流入、板块、MA20、涨停日期、涨停涨幅、距涨停天数、市场热点标签和综合评分，按评分排序。

## 本地运行

双击 `run_server.bat`，或执行：

```bash
python server.py
```

默认端口 8787，浏览器打开：

```text
http://127.0.0.1:8787
```

如果端口被占用，可换端口启动：

```bash
python server.py 8788
```

## 重构说明

2025 年对代码进行了纯结构重构，前后端对外功能保持不变：

- 后端：原 `server.py`（1200+ 行单文件）按职责拆分为 `stockreview/` 包，
  HTTP 路由、API 路径、JSON 响应结构与缓存 TTL 均未改变。
- 前端：原 `static/app.js`（单文件）拆分为 `static/js/` 下的 ES 模块，
  页面结构、渲染内容与交互行为未改变。
- 盘中监控后端改为复用 `stockreview` 包的 HTTP 请求与配置常量，
  快照组装逻辑与输出结构未改变。
- 验证：`tests/equivalence_test.py` 用相同离线假数据分别驱动
  git HEAD 原版与重构版，逐字段断言输出一致；`tests/verify_schema.py`
  对运行中服务的各 API 端点做基线结构比对。

## 数据说明

- 数据源为东方财富公开行情接口，实时/收盘口径。
- 服务端缓存 30 秒，前端每 30 秒自动请求一次。
- 盘中显示实时数据，收盘后显示当日最终数据；非交易日涨停池等数据可能为空。
- 本工具仅供学习研究，不构成投资建议。
